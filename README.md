# amber-snapshot-language-support README

This extension adds language support for the [syrupy](https://syrupy-project.github.io/syrupy/) default snapshot extension language 'Amber'. The initial use case was adding a language ID to link editor settings in VS code.

## Features

- Basic syntax highlighting (using Python as embedded language for snapshot content)
- Default settings that turn off automatic formatting
- Outline generation
